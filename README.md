One razor-sharp line that gets you out of a pointless meeting. An AI judge
pairs excuses head to head and crowns the biggest laugh.

## The entry

> I can't join—my camera is broken, my mic is haunted, and my soul left the chat at 9:15.

## How it works

`main.ts` writes exactly that one line (87 characters) to `/output/entry.txt`
— no trailing newline, no extra text. Run it with Node 22.6+:

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else instead.
